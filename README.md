# keio-legal

Pages légales publiques de l'app iOS **Keio**, servies par GitHub Pages.

| Page | URL |
|---|---|
| Politique de confidentialité | https://blazmad.github.io/keio-legal/confidentialite/ |

Le code de l'app vit dans le dépôt privé `Blazmad/keio`. Ce dépôt est public **uniquement** parce
qu'Apple exige une URL publique pour la politique de confidentialité : il ne contient que du HTML
statique.

Toute modification de la politique : changer la date « Dernière mise à jour » en tête de page.
